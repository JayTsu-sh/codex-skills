# Codex Skills

可单独安装的 Codex skills 集合。每个 skill 位于 `skills/<skill-name>/`，目录中包含
`SKILL.md` 及该 skill 需要的脚本和参考资料。

## Skills

- [`codex-agent-flow`](skills/codex-agent-flow/SKILL.md)：协调式开发流程、上下文控制、用量统计与 A/B 评估。

## 安装

使用 Codex 的 `skill-installer`，仓库选择 `JayTsu-sh/codex-skills`，路径选择
`skills/codex-agent-flow`。安装后在新会话中调用 `$codex-agent-flow`。
