# 本地软件检查

```bash
python3 "${CODEX_HOME:-$HOME/.codex}/skills/codex-agent-flow/scripts/run_check.py" \
  --cwd /absolute/path/to/repo \
  --timeout 1800 -- cargo test
```

`1800` 是本地检查示例，不是磁带超时。依据本地基线选择，不调整已有硬件超时。
运行器不会选择测试；fmt/check/clippy 等仍由仓库规则决定。它用参数数组直接执行命令，
保存完整 stdout/stderr、命令、工作目录、时间和退出码；原始日志默认在唯一临时目录，
可用 `--log-dir <长期目录>` 保存。命令参数会写到 result.json，勿传明文凭据。

成功仅显示 PASS、耗时、日志和结果文件。失败显示前 8 段错误和末尾 12 段输出，
每段不超过 240 字符；摘要不够时按关键词/区段读原日志。正常非零退出码保留，
超时 124，中断 130；超时/中断仅终止该次启动的本地进程组。
它不是沙箱：仅用于已明确授权的本地软件检查，不包裹磁带命令、部署或远程 SSH。

在 Codex 中，执行它后若得到 session_id，就等待同一任务；不要重复启动检查。
当前实现是前台包装器，不承诺掉线存活或后台完成通知。没有通知能力时仍需宿主等待，
不能将等待次数下降或费用下降写成已验证事实。

当前运行器没有通过结果缓存。再次调用就会真的运行，避免错误跳过。减少重复测试靠明确的
最终验收边界；有相关改动、环境变化或新疑点时照常复测。真实设备验证始终另列。
